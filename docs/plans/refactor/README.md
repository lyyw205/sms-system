## 원본 vs 생성물 — 이 구분이 중요합니다

```
backend/app/**.py ──┬─▶ functions/*.yaml ────┐
   (AST 기계 추출)   │                        ├─▶ 함수명세/*.md · _진행률.md
                    │   semantics/*.yaml ────┘
                    │      ★ 손으로 쓴 의미 — 편집은 여기서만
                    │
                    ├─▶ variables/01~04.yaml ─┐
                    │   variables/10-domain-axes.yaml ★ ─┴─▶ 변수명세/*.md
                    │
                    └─▶ 코어도출/요약.md
```

| | 원본 (git 추적) | 생성물 (gitignore) |
|---|---|---|
| 산문 문서 | `00~06-*.md` | — |
| 의미층 | `semantics/*.yaml` (21) | — |
| 도메인 값 사전 | `variables/10-domain-axes.yaml` | `변수명세/*.md` |
| 함수 골격 | — | `functions/*.yaml` · `함수명세/*.md` |
| 코어 계산 | — | `코어도출/요약.md` |

생성물은 커밋하지 않습니다. **코드가 바뀌면 조용히 낡기 때문**입니다
(실제로 8/6 조사 후 일주일 만에 커버리지가 100% → 95% 로 떨어졌습니다).

```bash
bash scripts/spec/regen.sh    # 전부 재생성 (수 초)
```

`함수명세/*.md` 를 직접 고치지 마세요 — 다음 실행에 덮어써집니다.
고쳐야 할 내용은 `semantics/*.yaml` 에 씁니다.
