# 지금까지 한 일 — 전체 정리

> 작성 2026-08-06 · **코드는 한 줄도 바꾸지 않았습니다.** 전부 조사와 문서입니다.

---

## 1. 무엇을 하려는 건가

**목표**: 지금 있는 기능을 **하나도 잃지 않고** 코드 구조를 다시 짠다.

그러려면 순서가 이래야 합니다:

```
① 지금 뭐가 있는지 전부 안다   ← 지금 여기까지 끝남
② 그중 뭐가 핵심(코어)인지 안다  ← 1차 계산 끝남
③ 어떻게 다시 조립할지 설계한다  ← 아직
④ 실제로 옮긴다                ← 아직
```

**①을 건너뛰면 안 되는 이유**: 이 코드에는 "왜 이렇게 짰는지" 이유가 있는 곳이 아주 많습니다.
겉보기엔 이상해 보이는데 실제로는 사고를 막고 있는 코드들입니다. 모르고 "정리"하면 그 사고가 다시 납니다.

예를 들면:

- 같은 파일 안에서 **정반대 정책**이 공존합니다. 방 배정은 충돌 시 기존 손님을 밀어내고, 날짜 정리는 밀어내지 않고 공존시킵니다. 둘 다 맞습니다. "통일"하면 사고입니다.
- 분할 예약 행 수를 셀 때 **취소된 것도 포함**합니다. 살아있는 것만 세면 정리 직후부터 영원히 잘못된 경보가 뜹니다.
- 네이버 시각을 파싱할 때 시간대를 **제거**해야 합니다. 변환하면 9시간이 밀리고, 안 떼면 5분마다 전체 행이 쓸데없이 업데이트됩니다.

이런 게 수백 개입니다. 그래서 **전수조사**를 먼저 했습니다.

## 2. 어떻게 조사했나

혼자 읽고 요약하면 빠뜨립니다. 그래서 **두 층으로 나눴습니다.**

```
① 기계가 먼저 전부 뽑는다  →  빠뜨릴 수가 없다
       ↓
② 사람(제가)이 의미를 채운다  →  "왜 이렇게 짰나"
       ↓
③ 스크립트가 합쳐서 문서를 만든다  →  두 번 쓰지 않으니 어긋나지 않는다
```

기계가 뽑은 것 (함수 하나하나):
시그니처 · 원본 주석 · **분기 조건 전부** · **조기 차단 조건 전부** · 예외 발생·처리 · 진단로그 이름 · 건드리는 데이터 · DB 부작용 · 호출하는 함수

이러면 진행률이 곧 남은 일이 됩니다. "다 봤나?" 를 고민할 필요가 없습니다.

## 4. 조사하면서 알아낸 것들

### 4-1. 이 시스템에서 **진짜로 강제되는 규칙은 하나뿐**입니다

| 규칙 | 어떻게 지키나 | 우회 사례 |
|---|---|---:|
| **테넌트 격리** | 컨텍스트 없이 조회하면 **예외를 던짐** | **0건** ✅ |
| 예약 필드 변경(Mutator) | "이걸 쓰세요" 약속뿐 | **24곳** 🔴 |
| 칩 만들기(chip_store) | 약속뿐 (최근 정리해서 지금은 지켜짐) | 0건 |
| 방 배정 | 관문 자체가 없음 | — |

같은 코드베이스, 같은 사람이 짰는데 결과가 갈렸습니다. **차이는 "우회하면 터지게 만들었나" 하나**입니다.

→ 리팩토링의 핵심은 폴더를 나누는 게 아니라 **관문을 강제하는 것**입니다.

### 4-2. 문자가 손님에게 잘못 나가지 않게 하는 장치가 겹겹입니다

발송 직전에 **5겹 차단**이 있습니다:

1. 전화번호 없음
2. 전화번호 형식 이상 (숫자 9~15자리 아님)
3. **템플릿 없음** ← 이게 없으면 `[Template 'xxx' not found]` 라는 **글자가 그대로 손님에게 발송**됩니다
4. 방 정보를 쓰는 문자인데 방 정보가 빔 (빈칸 문자 방지)
5. 치환 안 된 `{{변수}}` 가 남음

발송 성공하면 **즉시 저장**합니다 — 뒤에서 멈춰도 중복 발송이 안 되게.

### 4-3. 실제 사고에서 나온 방어들

코드에 "왜 이렇게 했는지" 가 적혀 있는 것들입니다.

| 방어 | 막고 있는 사고 |
|---|---|
| 네이버 쿠키 50자 미만 거부 | `NAC`, `.` 오입력 (7/10에 3번째) |
| 취소건을 전부 처리 | 재예약한 사람의 취소를 조용히 삼키던 버그 |
| 분할 형제를 연박 감지에서 제외 | 가짜 연박 체인이 생겨 대표 예약이 누락됨 |
| 시간대 제거(변환 아님) | 확정 예약마다 5분마다 쓸데없는 업데이트 |
| 자동배정 명시 테넌트 필터 | 다른 펜션 스케줄이 새어 들어와 엉뚱한 문자 발송 |
| `func.count()` 대신 `func.count(예약.id)` | 자동 테넌트 필터가 안 걸려 남의 데이터 집계 |

**여러 곳이 각자 지키고 있는 데이터**가 숫자로 드러났습니다:
